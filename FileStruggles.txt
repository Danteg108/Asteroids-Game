Some of the errors that I encountered during the project was many null pointer exceptions. I ran into many errors where the compiler ran a null object of an Asteroid or a bullet. To fix this error, I added if statements to check if they are null or not. Another error I was encountering was the bullets would not fire, which is because I set the position to repaint at the ship's position preventing it from updating when I clicked the space bar. I also had struggles when I compared the Circle with the Polygon, or the bullet with the asteroid. This is because I originally used points.length on the outer layer before asteroids, which prevented me from getting the proper points for the asteroid, leading to an error in the compiler.
